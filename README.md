# Mis Cuentas

App personal de gastos e ingresos para Android:

- Panel con lo que queda del mes, gasto por categorías, avisos y objetivo de ahorro.
- Movimientos del banco automáticos (Enable Banking, gratis para uso personal) con clasificación que aprende.
- Notificación fija y widget para anotar gastos sin abrir la app.

Cada cambio en `main` compila un APK nuevo y lo publica en **Releases**.
